# Security policy

## Supported versions

Security fixes target the current default branch. Older commits and other
branches do not have a separate backport or security-support commitment.

## Reporting a vulnerability

Report suspected vulnerabilities privately to
[jorgesaldivar@gmail.com](mailto:jorgesaldivar@gmail.com), with
`GuaraScraper security report` in the subject line.

Please do not disclose vulnerability details in a public issue or pull request
before maintainers have had an opportunity to investigate and coordinate a fix.

Include, where available:

* The affected commit and component (CLI, scraper, processor, or dependency)
* Python version, operating system, and relevant dependency versions
* A minimal reproduction using local fixtures or synthetic input
* Expected and observed behavior, potential impact, and any proposed fix

Remove credentials and unrelated personal or scraped content from reports.
Maintainers will review the report, request additional details if needed, and
coordinate remediation and disclosure with the reporter. There is no guaranteed
response or remediation timeframe.

For ordinary bugs, setup questions, and feature requests, use
[GitHub issues](https://github.com/guaran-ia/guarascraper/issues).
